# Vibe Coding Lab: Enterprise Identity Decoder 🔐

This project is an experiment in **Vibe Coding**—moving from manual syntax to high-level architectural direction. As a specialist in technical implementations and security, I’ve designed this tool to bridge the gap between complex identity protocols and human-readable insights.

### 🌊 The Vibe
"Create a lightweight, extensible Python utility that can ingest, decode, and validate JWT and SAML tokens without the overhead of a full enterprise framework. It should feel like a 'Swiss Army Knife' for an Implementation Manager."

### 🛠️ Tech Stack
*   **Prompted by:** LLM-assisted workflow
*   **Core:** Python (transitioned from my C#/.NET background[cite: 1])
*   **Security Focus:** JWT, SAML, and Cryptography[cite: 1]

### 🚀 Key Features
*   **Automatic Detection:** Identifies token types (JWT vs. SAML)[cite: 1].
*   **Claims Extraction:** Beautifully formatted output of identity claims[cite: 1].
*   **Validation Hints:** Basic checks for expiration and signature presence[cite: 1].
